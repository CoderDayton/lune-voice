Hi team, here's the weekly status update for the platform migration project. This week we completed the database schema changes and deployed them to staging. The new connection pooling layer is handling about 2000 requests per second without any issues, which is well above our target of 1500. We did run into a problem with the session store. The Redis cluster was dropping connections under load because the timeout was set too low. We bumped it from 5 seconds to 30 seconds and that resolved it. Next week the plan is to start migrating the user-facing API endpoints. We'll do this in batches, starting with the read-only endpoints first since those are lower risk. The write endpoints will follow once we've confirmed everything is stable. One thing I want to flag is that we'll need to coordinate with the mobile team on the API versioning. Their next release is scheduled for March 15 and we need to make sure the new endpoints are backward compatible. I've set up a meeting with Sarah and Marcus to discuss the details on Thursday.
